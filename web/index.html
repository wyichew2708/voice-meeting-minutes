Before you record

This records everyone in the room. Tell them, and get their agreement — in many places that is a legal requirement, not a courtesy.

Recordings, transcripts and voiceprints are stored in this browser on this machine. Nothing is uploaded except the transcript text, which is sent to the minutes API you configure, when you press Write minutes.

If you use the browser recogniser, microphone audio is also sent to Google for transcription. Switch the engine to Whisper in Settings to keep audio on this machine.

Settings

Speech recognition

Whether en-SG reaches a Singapore-tuned recogniser is undocumented, and there is no Singlish finetune behind it either way.

The Singlish models ship safetensors, not ONNX. Convert once with tools/export_singlish_onnx.py and pick local export, or the Hub entries above will fail to load.

Speaker identification

The clustering thresholds are calibrated for ECAPA's geometry. The built-in embedder separates clearly different voices but is not a speaker-verification model — expect to rename people by hand.

Minutes API

The key is stored in this browser and sent to the base URL above, from this page. A wrong base URL is a leaked key. Anything speaking the OpenAI chat-completions shape works — including a vLLM or Ollama server on your own network.
